# ELITA — A Potential Partnership

A standalone, private capital partnership presentation and daily financial simulator. The complete Next.js application lives at this repository's root, ready to import as a separate Vercel project.

## Deploy through your connected Vercel integration

Import `JakeKascade/elita-capital-simulator`, branch `codex/elita-interactive-proposal`, with root directory `.`. Use a separate Vercel project, the Next.js preset and Node.js 24.x. Installation and build commands are saved in `vercel.json`.

Set **`ELITA_ACCESS_PASSWORD`** securely in Vercel for Preview and Production. Optionally set `ELITA_ACCESS_USER` (defaults to `elita`). These are server-only settings; never use `NEXT_PUBLIC_` prefixes. The application deliberately returns HTTP 503 until the production password is configured, then challenges unauthenticated requests with HTTP 401.

No `VERCEL_TOKEN` or Vercel login is needed in this development environment. Deployment is handled separately through your connected integration. See [the deployment handoff](docs/DEPLOYMENT.md) for the integration prompt and verification steps.

## Run locally

Uses Node.js 24.x (validated with Node 24.19.0) and npm. The Node version is declared in `package.json` and `.node-version`.

```sh
git clone --branch codex/elita-interactive-proposal https://github.com/JakeKascade/elita-capital-simulator.git
cd elita-capital-simulator
npm ci
npm run dev
```

The development server binds to the loopback interface on port 3000. No credentials are needed for local loopback development. Production always requires server-side credentials. No external services, database, analytics, remote fonts or API keys are used by the simulator.

```sh
npm test                 # financial engine, exports, access verification
npm run typecheck
npm run build
npm run test:security    # build first; tests real production HTTP protection
npm run test:browser     # desktop, tablet and mobile Chromium
```

Browser tests start this checkout's own development server on port 3100, independently of a manually started server on port 3000. They use system Chromium when available. Otherwise run `npx playwright install chromium`. Set `CHROMIUM_PATH` to use another Chromium installation. The PDF and screenshots generated by tests are private local artifacts under the ignored `artifacts/` directory.

## What is included

- Official supplied ELITA artwork, Optician Sans labels and Unica77 type hierarchy; off-white, charcoal, deep red and champagne from the supplied document system.
- Six editorial sections, capital recycling and profit-allocation diagrams.
- Live capital, margin, utilisation, settlement and term controls; 90/180-day exit illustrations; a reset action.
- Three settlement comparisons, chart inspection, utilisation taper, zero-or-positive monthly demand limits, and a conservative second-half sensitivity.
- Separate capital ownership, trading allocations, withdrawals, fee, at-term balances and post-wind-down payouts.
- Monthly viability table derived from the same ledger and its uncapped companion run.
- Exact-cent JSON ledger and CSV exports; an A4 print presentation that includes the current assumptions and methodology.
- Server-side access protection for the whole application, including scripts, images and fonts. Missing production credentials return HTTP 503; unauthenticated requests return HTTP 401.

## Files

- `src/lib/model.ts`: pure financial engine; money outputs are integer AUD cents.
- `src/lib/export.ts`: exports derived from the same engine.
- `src/components/`: presentation, controls and SVG charts.
- `src/proxy.ts`, `src/lib/access.ts`: server-side HTTP Basic authentication gate.
- `tests/`: financial, browser and production access tests.

## Scope and important assumptions

All trading outcomes are hypothetical, before tax, FX movements, general overheads and counterparty default. New purchases stop at the selected term; final payouts include orderly settlement of existing purchases for up to one further settlement interval. The fund chart stops at the selected term. The separate 4% fee accrues only through that term, using Actual/365 on original capital; ELITA may need external funds to pay it. These are disclosed modelling conventions for discussion, not agreed legal terms.

The supplied Unica77 files do not establish an entitlement to host them as webfonts. Confirm the appropriate Lineto web-use licence before hosted sharing. See `docs/BRAND.md`. No deployment or DNS change is performed by this repository's build or tests. Configure the application password in the separate Vercel project before sharing its URL.
