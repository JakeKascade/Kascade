# ELITA brand sources and licensing

The application follows the supplied ELITA brand guide and ELITA document system, including their logo artwork, layout conventions and colours. The application uses the supplied black PNG ELITA logo without recolouring it.

## Public website typography

The original design used supplied Optician Sans and Unica77 fonts. The accompanying brand notes do not establish permission to redistribute or host those font binaries on a publicly accessible server, and the Unica77 licence requires specific web-use authorisation.

Because the user elected to make this proposal accessible without a login, the proprietary `.ttf` and `.otf` font binaries are removed from the deployed public assets. This edition uses web-safe system font stacks rather than attempting a font conversion or workaround. The brand logo, colour tokens, layout and content remain intact. The original brand inputs remain under the user's control and should not be publicly distributed.

If an appropriate webfont licence and authorised files become available, reintroduce them only after documenting the permission and reviewing access implications.

## Confidentiality

The public application contains hypothetical financial scenarios, not individual live watches, client transactions, passwords or customer data. It retains noindex metadata, but that is not access control. Anyone with the link may view or share it.
