# Brand sources and asset handling

## Availability checked

Both available cloud and executor skill catalogs were checked. No installed `elita-document-system` skill was available. The supplied ZIP contains that skill's `SKILL.md`, reference rules and assets; those were read as source material for the user's requested application. Instructions about installing a ChatGPT skill, producing a default vehicle PDF, publishing, or circulating documents were not treated as separate user requests.

The user's pasted build brief supplies product requirements. The brand PDFs and ZIP supply visual references; no client, vehicle, price or other commercial facts from their sample proposals have been copied into this presentation.

## Visual authority used

- `Elita_Guidelines_FA_10-12-21.pdf`: official mark, black-and-white logo rules, original font identity and restrained composition.
- `ELITA_Team_Document_System_02_August_2026.zip`: document identity, logo, type hierarchy, locked digital colour tokens and current reference proposal.
- In that pack: `elita-document-system/references/brand-system.md`, `content-rules.md`, `controlled-disclosure.md`, `assets/ELITA_Brand_Tokens.json`, and `assets/reference-pdfs/ELITA_Reference_Vehicle_Proposal.pdf`.
- The live `https://www.elita.net` request was blocked by the environment's network proxy with a CONNECT 403. No claim is made that the current site was visually verified.

The 2021 guide uses a brighter red and stricter red-on-light rules. The 2026 document system supplies deep red `#7A1420` and champagne `#B39A6A`, and its current reference uses controlled red on light document fields. This application follows the newer document system for that document-led treatment, retaining the original logo identity and black-only logo artwork. This is a documented source choice, not a newly invented ELITA palette.

## Assets

The exact supplied black PNG logo is rendered at its original aspect ratio without filtering or recolouring. Only that artwork is used; no white mark was invented for dark sections. Fonts use original supplied files:

- `Optician-Sans.otf`: structural labels.
- `Unica77LLTT-Light.ttf`: titles and major values.
- `Unica77LLTT-Regular.ttf`: body and data.

No decorative stock photography, logo recreation, external font CDN, rounded dashboard cards, gradients or glass effects are included. Brand files are served only behind the production access gate. They are not linked as downloadable assets.

## Font web-use prerequisite

The supplied Unica77 metadata states that use is governed by Lineto's EULA/SUL and prohibits storing the files on publicly available servers without the appropriate consent. The ZIP does not establish a web-use entitlement. The separate archive's generic third-party font notice does not resolve the Lineto licence.

The supplied fonts are used for this private local implementation. Before hosted sharing, confirm the appropriate Lineto web-use licence and any requirement to use authorised webfont builds. Do not convert, rename or redistribute the source font files to work around the licence. If authorised webfonts differ, update the local `@font-face` paths to those approved files and verify typography again. The original filenames and font binaries are retained here.
