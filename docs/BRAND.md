# ELITA brand sources and webfont usage

The ELITA application follows the supplied official brand guidelines and ELITA document system. The original black ELITA logo is rendered at its supplied aspect ratio without recolouring.

## Typography
Jake has confirmed that use of the supplied ELITA fonts on this site is approved. The website therefore retains the supplied original ELITA typography:
- Optician Sans — labels and structural accents.
- Unica77 Light — headings and significant figures.
- Unica77 Regular — body and tabular data.

The original brand font binaries are restored unchanged in the public asset directory for browser font loading. The source files are not being provided as independent downloads in the proposal, but any files served by a publicly accessible website can be technically retrieved. Permission for web hosting remains the responsibility of the rights holder and site operator.

## Visual sources
- `Elita_Guidelines_FA_10-12-21.pdf` — logo usage and earlier visual rules.
- `ELITA_Team_Document_System_02_August_2026.zip` — current document identity, approved colour tokens and typography hierarchy.
- The live `www.elita.net` was not fetchable in the original build environment; the attached files were the visual authority.

## Privacy
The application is now accessible without a username or password. Robots metadata discourages indexing, but anyone with the link can open and share the content. Do not include live customer transactions or other sensitive material.
